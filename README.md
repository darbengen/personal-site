# Darben · 个人作品集

家齐 Darben 的个人展示网站，包含自我介绍、视觉作品与联系方式。

这是现有作品集的源码备份，保留原版页面、文案、图片和交互。

## 本地预览

无需构建或安装依赖。在本目录执行：

```sh
python3 -m http.server 8000
```

然后打开 http://localhost:8000 。

## 文件结构

- `index.html`：自我介绍、作品列表与联系方式。
- `css/main.css`：样式和响应式布局。
- `js/main.js`：页面交互。
- `assets/`：字体和图片。
- `works/`：作品素材。

作品链接沿用原站配置，部分跳转到其他网站，不包含在本仓库内。
